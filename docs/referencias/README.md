# Referências

Pasta local para material de referência visual e documental. **Nada aqui é versionado**
(veja `.gitignore`): são insumos de apoio, não código de produção.

## Como enviar prints de UI/UX

Ao trazer capturas de tela como referência de interface, salve os arquivos aqui usando um
nome que identifique a tela e o formato, por exemplo:

- `login-desktop.png`
- `dashboard-vendedor-desktop.png`
- `dashboard-vendedor-mobile.png`
- `prospeccao-desktop.png`
- `funil-desktop.png`
- `equipe-desktop.png`

Anexar as imagens diretamente no chat também funciona.

Para cada print, informe:

1. a qual tela do Lynk ele corresponde;
2. se é referência **desktop**, **mobile** ou ambos;
3. o que deve ser seguido (layout inteiro, apenas a paleta, apenas um componente).

## Regras de uso

As referências orientam **apenas aparência**: distribuição dos elementos, formato de
cards, espaçamentos, hierarquia visual, tamanho de botões, posicionamento de menus,
cores, tipografia e ícones.

Não são copiados conteúdo, textos, nomes, dados, marcas nem regras de negócio das
referências. A identidade aplicada é sempre **Lynk**, e em qualquer conflito
entre print e requisito escrito, prevalece o requisito.

A paleta e as decisões visuais vigentes estão em `docs/decisoes.md`. O conteúdo funcional
das referências originais já foi consolidado em `docs/requisitos.md`,
`docs/arquitetura.md`, `docs/decisoes.md` e `docs/modelo-dados.md`.
